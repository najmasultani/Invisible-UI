# Invisible

## Installation
Create virtual environment:
```bash
python -m venv .venv
```

Entering virtual environment:
```bash
source .venv/bin/activate
```

install dependencies
```bash
pip install -r requirements.txt
```

## Documentation

### Motivation
Are you ever watching a movie and you want to pause it or lower the volume to answer a text message, but the remote is far away?

Our motivation is from situations like projectors, where it can be difficult to navigate, or teacher/professor lecture slides that can be easier to navigate. 

Our group is designing Invisible, a hand sign detection application that will allow direct communication to your device.
